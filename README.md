# 🌐 Personal Portfolio Website
This is a personal portfolio website built to showcase my skills, projects, education, and work experience in a clean and visually engaging manner. The site acts as a central platform for potential employers, collaborators, or anyone interested in learning more about me and my work.

## 🔍 Overview
The portfolio is designed to leave a lasting impression while maintaining simplicity and ease of navigation. It features detailed sections on technical skills, academic background, project highlights, and a contact form for direct communication — all built with responsive and modern web technologies.

## 🚀 Features
👋 Introduction Section: A welcoming intro about who I am

💻 Skills Showcase: Highlights my technical stack and proficiencies

🎓 Education & Work Experience: Summarizes my academic and career journey

🛠️ Projects: Showcases selected notable projects with brief descriptions

📬 Contact Section: Includes email, phone, and social links for reaching out

💌 EmailJS Integration: Enables real-time messaging through a dynamic contact form

## 🛠️ Technologies Used
Frontend: React, JavaScript, HTML, CSS

Messaging Service: EmailJS – to send messages directly from the contact form
